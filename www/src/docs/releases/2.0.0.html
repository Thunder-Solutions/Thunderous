Release Version 2.0.0 (Latest: 2.3.13) The following changes were made in version 2.0.0 of Thunderous:
  • Minor release: 2.4.0 Added effect arguments for better conditional signal tracking, restructured render bindings for better performance, improved signal debugging with actual subscriber names, and optimized fragment persistence to avoid cloning.
  • Minor release: 2.3.0 Added HTMLCustomElement type for convenience. Read more about types.
  • Minor release: 2.2.0 Added property signal initializers. For example: const [prop, setProp] = propSignals.prop.init('initial') Read more about properties.
  • Minor release: 2.1.0 Added property binding syntax via HTML templates. Read more about properties.
  • Removed deprecated type RenderProps in favor of RenderArgs.
  • Added getter() method to RenderArgs. Read more about getters.
  • Deprecated the customCallback() method, which was used to register callbacks on the class instance. Now, callbacks are now bound directly to DOM nodes. Read more about event binding.
  • Removed scoped custom element registry polyfill from the library. This must now be included separately, as an optional peer dependency. Read more about registries.
